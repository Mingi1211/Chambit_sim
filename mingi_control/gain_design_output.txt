① 중력 보상 [문서 2·5쪽]  τ += g(q). Pinocchio RNEA(q,0,0)은 중력을 지탱하는 토크라 +g. 게인 없음
② 무게 피드포워드 [문서 3쪽]  τ += J_vᵀ[0,0,F]ᵀ, 손당 F = m g/4 = 4.905 N → K_z는 추정 오차만 버팀

③ 제어 주기 상한 [문서 4쪽, MR 외 경험칙]  f = 100 Hz, T = 0.01 s → ωn ≤ 2πf/10 = 62.8 rad/s
   이유: 디지털 제어는 T마다 계산해 다음 T 동안 유지(영차 홀드) → 평균 T/2 지연 = 위상 지연 ωT/2.
   ω = ωs/10이면 지연이 π/10 = 18°로, ζ=1 연속시간 설계(오버슈트 0)가 이산 구현에서도 유지됨. 더 빠르면 위상 여유가 줄어 진동
   축별 K_max = Λ_min ωn,max²: x 8245, y 12730, z 19622 N/m, 회전 [ 51.9 826.7 638.9] N·m/rad

④ 마찰 deadband 하한 [문서 3·4쪽]  F_fric,tip = J̄ᵀ τ_stiction,  K_min ≥ F_fric,tip / δx  (δx = 5 mm)
   시뮬: τ_s = 0.0 (플랜트에 정지마찰 없음) → F_fric = 0 → K_min,fric = 0, 이 하한은 시뮬에서 비활성
   실물 감도(측정 전): 모든 관절 τ_s = 0.1 N·m이면 손끝 F_fric (x y z) = [1.44 1.22 1.66] N → K_min = [287. 245. 333.] N/m
   실물: 관절마다 전류를 천천히 올려 움직이기 시작하는 토크 = τ_s 측정 → 이 식에 대입 (calib 절차)

⑤ K_z [문서 3쪽]  K_z ≥ F/Δz_max
   피드포워드 없으면 F = m g/4 = 4.91 N → K_z ≥ 981 N/m
   피드포워드 있으면 F = 20%·m g/4 = 0.981 N → K_z ≥ 196 N/m (마찰 하한 0)
   설정 K_z = 400 N/m (하한의 2배: 무게 오차가 가정의 2배여도 처짐 5 mm 이내). 상한 19622 N/m → 충돌 없음
   리더·팔로워 같은 K_z: 같은 하중에 같은 처짐 → 박스 수평 유지 (문서 3쪽 "K_z는 둘 다")

⑥ K_xy [문서 3쪽]  베이스 간 거리 오차 Δ = 57.5 mm 먼저 산정(실측)
   리더 상한 — 축별 근사 K ≤ Λ_ii ωn,max² (x 8245 N/m)만으로는 부족: 가벼운 손목 관절(M_ii ≈ 0.01 kg·m²)로
     옮겨진 강성·감쇠가 관절 공간에서 더 빠른 모드를 만듦 (K_L 3000이면 최고 모드 95 rad/s, 11/5 시뮬 100 Hz에서 발산 확인)
   → 문서 4쪽 두 이산 조건을 관절 공간 전체에 적용한 엄밀판: 영차 홀드 이산 폐루프 스펙트럼 반경 ρ(Φ) < 1 (여유 0.99)
     실물 플랜트(T = 0.01 s, 손목 armature 0.05 kg·m²)에서 K_L,xy ≤ 508 N/m → 설정 K_L = 500
