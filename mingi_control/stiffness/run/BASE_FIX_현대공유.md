# 현대 베이스 노드 수정 공유 — 박스 파지 곡선 주행 출발 지연 (11/24, 김민기)

**기존 동작은 바뀌지 않음.** 새 기능은 모두 파라미터로 켜고, 기본값은 꺼짐(현대 코드 그대로). 켜는 파일: `mingi_control/stiffness/run/base_fix_s00575.yaml`, `base_fix_s020.yaml`

## 1. 문제 (11/23)
- 박스를 쥔 곡선 주행 5회 중 4회: 10 s 패턴 시작 후 두 베이스가 3 ~ 6 s 안 움직이다가 **서로 다른 시각에 출발** → 주행 방향으로 0.16 ~ 0.76 m 어긋난 채 끝남, 2 m 중 0.5 ~ 1.7 m만 감.

## 2. 원인 — 정렬 판정 오탐
- `base_move_node.align_tick`: 정렬 중(0.005 m/s 방향 지령) **차체 속도의 이동 방향 성분 > 0.003 m/s**면 "정렬 완료" → 10 s 패턴 시작.
- 실제 바퀴 정렬은 약 5.9 s(시뮬) 걸림 (조향 약 0.27 rad/s로 1.57 rad 회전, 11/24 관절 기록).
- 11/23 로그 16회: 정상 출발 런은 "정렬 완료"가 5.84 ~ 5.93 s, 출발 지연 런은 **0.64 ~ 3.04 s** → 바퀴가 다 돌기 전에 판정.
  박스를 쥐면 팔 임피던스 반력이 차체를 밀어 차체 속도가 0.003 m/s를 넘는 것으로 봄.
- 판정 뒤 패턴은 시작됐는데 스워브 제어기는 조향 오차가 기준(`steering_alignment_start_angle_error_threshold` 0.02 rad)보다 크면 구동을 막음 → 남은 정렬 시간만큼 서 있다가 로봇마다 다른 시각에 출발. 패턴은 개루프 속도라 멈춰 있던 만큼의 이동량이 사라짐.

## 3. 수정 (파라미터, 기본 꺼짐)
| 파라미터 | 기본 | 내용 |
|---|---|---|
| `align_mode` | `chassis` (기존) | `steering`: 두 로봇 조향 관절 3개가 모두 이동 방향과 `align_tol`(0.02 rad = 제어기 시작 기준) 이내로 `align_hold`(0.2 s) 유지되면 정렬 완료. 바퀴는 뒤로도 구동하므로 π 차이는 같은 정렬. 완료 순간 위치를 패턴 기준점으로 |
| `start_floor` | false | 패턴 초반 지령 속도가 `align_speed`보다 작으면 `align_speed`로 (5차 프로파일 시작 속도 0 → 제어기가 정지 상태로 돌아가 재정렬하는 것 방지) |
| `track_feedback` | false | MR 식 (11.17) ẋ = ẋ_d + K_p (x_d − x)를 **경로 진행 방향**에만: 속도 크기 = 피드포워드 + `track_kp`·(진행 방향 위치 오차), 방향은 피드포워드 그대로. x = Gazebo 차체 자세(`base_odometry`), 실물은 바퀴 오도메트리로 같은 구조 |
| `lag_limit`, `lag_time` | 0.05 m, 1 s | 한 로봇이 지령 위치에서 0.05 m 넘게 1 s 이상 뒤처지면 상태에 `tracking_invalid` 기록 (비교에서 제외용) |

- 옆 방향까지 위치 보정을 걸었던 첫 버전은 실패: 저속에서 옆 보정이 진행 방향을 크게 틀어 조향이 다시 정렬하느라 구동이 막힘 (조향이 느림 0.27 rad/s) → 진행 방향만 보정.
- 바뀐 파일: `base_move_node.py`(위 파라미터·`tracked_motion`·조향 정렬 판정), `base_move_curve_node.py`(로봇별 곡선 여부 `curved`), `base_interface.py`(피드백에 조향 관절 각도 `steer` 추가), `launch/base_move_curve.launch.py`(`params:=<yaml>` 인자, 비우면 기존과 같음), `test/test_simulation.py`(effort 모드 F/T 브리지 토픽 기대값 추가). 단위 테스트 102개 통과.

## 5. 남은 것
- 옆 이탈 0.2 m: 9/11 합격. 불합격 2회는 곡선 후반 로봇1 추종 오차 0.052·0.059 m (조향 0.27 rad/s가 방향 변화 ±0.3 rad를 겨우 따라감)
- 시뮬 직후 간헐적으로 스워브 제어기 미활성 → 시작 거부 (재시도하면 됨)
