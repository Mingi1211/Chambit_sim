# 하위 제어 게인 근거 — 사양 → 문서 식 → 값 → 시뮬 검증

김민기 · 2026-11-05 · 계산: `gain_design.py` (실행하면 아래 숫자가 그대로 출력되고 `gains.yaml`로 저장 → `impedance_node`·`transport_scenario`가 읽음)

- **근거:** 「작업공간 임피던스 제어 PD gain 설정」(아래 '문서 n쪽'), MR 8.6·11.2.2·11.4.1·11.7.1, Khatib(1987)
- **설계 원칙:** 강성은 모두 문서 1쪽 정적 순응 e_ss = K⁻¹F에서 **K = F / e**로 정합니다. 어떤 힘 F를 어떤 오차 e 안에 버티게 할지가 사양입니다.
- **계산 자세:** Λ, J̄ᵀ, 그리퍼 기구비는 실제 파지 자세에서 Pinocchio로 계산했습니다. 이 자세는 11/4 파지 직후 로그의 관절각입니다.

## 0. 사양 (정한 숫자와 이유)

| 기호 | 값 | 이유 |
|---|---|---|
| f_ctrl, T | 100 Hz, 0.01 s | 실물 ros2_control `update_rate: 100` (ffw_sg2_follower_ai_hardware_controller.yaml) |
| m_box, 손 수 | 2.0 kg, 4 | 두 로봇 × 양팔. 손 하나가 m g/4 = **4.905 N** |
| 무게 추정 오차 ε | 20 % | 실물 박스는 내용물에 따라 질량이 달라짐 |
| Δz_max | 5 mm | 문서 3쪽 값. 내려놓기 마지막 구간(1 cm)의 절반이라야 받침대에 수평으로 닿음 |
| Δ (베이스 간 거리 오차) | **57.5 mm** | **실측**: 현대 스워브 2 m 주행에서 두 베이스 상대 위치 변화의 최대값 (`base_error.py`) |
| F_int,max | 15 N | 문서 3쪽 값. 같은 숫자로 그리퍼 쥐는 힘을 설계(⑨)하므로, 이 이하면 미끄러지지 않음 |
| δx (목표 정밀도) | 5 mm | 리더 경로 정밀도이자 마찰 deadband 허용치(문서 3·4쪽). z와 같은 기준 |
| τ_stiction (시뮬) | 0 | 물리 모델 URDF `<dynamics>`에 damping 0.1만 있고 friction이 없음 (확인함) |
| θ_max | 2° | 박스 기울기 판정 기준과 같음 |
| μ, 쥐기 안전율 | 1.0, 2 | 손끝-손잡이 마찰 (robots.yaml) |
| ζ | 1 | 임계감쇠 → 오버슈트 0. 손이 박스·상대 로봇을 밀고 들어가지 않음 (문서 2쪽) |

## ① 중력 보상 — 가장 먼저 켬

- **식:** τ += g(q). Pinocchio `computeGeneralizedGravity` = RNEA(q, 0, 0)은 중력을 **지탱하는** 토크라서 +g로 더합니다(문서 5쪽 실수 3).
- **게인:** 없음. 모델이 맞으면 토크 모드로 바꿔도 처지지 않습니다.

## ② 박스 무게 피드포워드 (문서 3쪽)

- **식:** τ += J_vᵀ[0, 0, F]ᵀ, 손당 F = m g/4 = 4.905 N
- **효과:** 무게를 강성으로 버티지 않으므로 K_z는 **추정 오차만** 감당하면 되고, 그만큼 작게 쓸 수 있습니다(⑤).
- **램프 시간:** 2·T_s,z = 1.43 s. 무게를 z 정착시간보다 천천히 얹어 과도 처짐을 막습니다.

## ③ 제어 주기 상한 (문서 4쪽, [MR 외] 경험칙)

- **식:** ωn ≤ 2πf/10 = **62.8 rad/s** (f = 100 Hz)
- **이유:** 디지털 제어는 T마다 계산한 토크를 다음 T 동안 유지합니다(영차 홀드). 그래서 평균 T/2만큼 늦고, 위상이 ωT/2만큼 밀립니다. ω = ωs/10이면 이 지연이 π/10 = 18°에 그쳐, 연속시간 설계(ζ = 1 → 오버슈트 0)가 이산 구현에서도 거의 그대로 유지됩니다. 이보다 빠르면 위상 여유가 줄어 진동합니다.
- **축별 근사 상한:** K_max = Λ_min ωn,max² → x 8245, y 12730, z 19622 N/m
  - 축별 근사(Λ 대각만 사용)로는 이 상한이 **부족**하다는 것을 ⑦에서 확인했습니다.

## ④ 마찰 deadband 하한 (문서 3·4쪽)

- **식:** F_fric,tip = J̄ᵀ τ_stiction (J̄ᵀ = Λ J M⁻¹),  K_min ≥ F_fric,tip / δx
- **시뮬:** τ_s = 0 → K_min = 0. 시뮬에서는 이 하한이 걸리지 않습니다.
- **실물 감도:** 모든 관절 τ_s = 0.1 N·m이면 (관절별 부호가 최악으로 겹칠 때)
  - 손끝 F_fric = (1.44, 1.22, 1.66) N
  - K_min = (287, 245, 333) N/m
- **실물 절차:** 관절마다 전류를 천천히 올려 움직이기 시작하는 토크(τ_s)를 측정해 이 식에 넣습니다.
  - 이 값이 ⑥의 팔로워 K_F(40 N/m)보다 커지면 팔로워가 마찰에 막혀 Δ를 흡수하지 못합니다. **실물 첫 확인 항목**입니다.

## ⑤ 수직 강성 K_z (문서 3쪽)

| 경우 | 남는 힘 F | K_z 하한 = F/Δz_max |
|---|---|---|
| 피드포워드 없음 | m g/4 = 4.91 N | 981 N/m |
| **피드포워드 있음** | ε·m g/4 = 0.981 N | **196 N/m** |

- **설정:** **K_z = 400 N/m** (하한의 2배, 무게 오차가 가정의 2배여도 처짐 5 mm 이내)
- **상한과 충돌 없음:** 상한은 19622 N/m(③)이고, 문서 4쪽 "중력 보상이 들어가면 충돌 없음"에 해당합니다.
- **리더·팔로워 같은 값:** 같은 하중에 같은 처짐이 생겨 박스가 수평으로 유지됩니다.

## ⑥ 수평 강성 K_xy — 리더–팔로워 (문서 3쪽)

1. **Δ 먼저 산정:** 57.5 mm (실측)
2. **리더 상한 = 안정성(⑦):** 실물 100 Hz에서 이산 폐루프가 안정한 최대값 → K_L,xy ≤ 508 N/m (ρ ≤ 0.99) → **K_L = 500 N/m**
3. **팔로워 상한 ① 내력:** Δ를 혼자 다 흡수해도 K_F·Δ ≤ F_int,max → K_F ≤ 15 / 0.0575 = 261 N/m
4. **팔로워 상한 ② 리더 정밀도:** 리더가 받는 반력 때문에 리더 오차가 δx를 넘으면 안 됩니다.
   - Δ·K_F/(K_L + K_F) ≤ δx → K_F ≤ δx·K_L/(Δ − δx) = 47.6 N/m
5. **팔로워 하한:** 마찰(④). 시뮬은 0 → **K_F = 40 N/m**
6. **확인 (직렬 스프링):**

| 항목 | 값 | 기준 |
|---|---|---|
| 실제 내력 Δ·K_L K_F/(K_L + K_F) | 2.1 N | ≤ 15 N |
| 리더 오차 | 4.3 mm | ≤ 5 mm |
| 박스가 리더를 따르는 비율 | 0.93 | — |

## ⑦ 감쇠·정착시간과 이산 안정 (문서 2·4쪽)

- **식:** D = 2ζ√(ΛK) (매 주기 현재 Λ로 다시 계산), T_s ≈ 5.8/ωn (ζ = 1, 2 %), 이산 감쇠 상한 D < 2Λ/T

| 축 | K [N/m] | Λ [kg] (r / l) | ωn [rad/s] | D [N·s/m] | T_s [s] |
|---|---|---|---|---|---|
| 리더 x·y | 500 | 2.09 – 4.54 | 10.5 – 15.5 | 65 – 95 | 0.37 – 0.55 |
| 팔로워 x·y | 40 | 2.09 – 4.54 | 3.0 – 4.4 | 18 – 27 | 1.3 – 2.0 |
| z | 400 | 6.09 / 4.97 | 8.1 / 9.0 | 99 / 89 | 0.72 / 0.65 |

- 모든 축이 ωn ≤ 62.8 rad/s, D < 2Λ/T를 만족합니다. D/(2Λ/T) = ζ ωn T이므로 ③을 지키면 감쇠 상한은 자동으로 만족됩니다.

**발견 — 축별 근사만으로는 안정성을 보장할 수 없음 (11/5 시뮬에서 확인)**

- **현상:** 처음에는 축별 근사만 보고 K_L = 3000, K_rot = 26 ~ 30을 줬습니다. 그런데 100 Hz 시뮬에서 토크 모드로 바꾸자 팔이 처지며 토크가 한계에 붙었습니다(발산).
- **원인:** 가벼운 손목 관절(M_ii ≈ 0.01 kg·m²)로 옮겨진 강성·감쇠가 관절 공간에서 더 빠른 모드를 만듭니다. 관절 공간 폐루프 최고 고유진동수는 95 rad/s로 62.8을 넘었습니다.
- **엄밀판:** 문서 4쪽의 두 이산 조건(ωnT, DT/Λ)을 관절 공간 전체에 한 번에 적용했습니다.
  - 영차 홀드 이산 폐루프의 **스펙트럼 반경 ρ(Φ) < 1**이면 안정입니다.
  - 플랜트: (M + armature) q̈ + 0.1 q̇ = τ
  - 제어: τ = −(JᵀKJ + N K_q) q − (JᵀDJ + N D_q) q̇
- **판정 결과:**

| 경우 | ρ(Φ) | 결과 |
|---|---|---|
| 실물 (100 Hz, 손목 armature 0.05) | 0.980 | 안정 |
| 시뮬 플랜트 (armature 0), 500 Hz | 0.995 | 안정 |
| 시뮬 플랜트 (armature 0), 100 Hz | 7.4 | 불안정 |

- **결론:** 시뮬 플랜트는 모터 회전자 관성이 없어 손목 관성이 실물보다 훨씬 작습니다. 그래서 같은 게인을 100 Hz로 돌리면 발산합니다. 게인은 실물 100 Hz 기준으로 정하고, 시뮬 검증은 500 Hz(`state_rate`)에서 했습니다.

## ⑧ 회전 강성·영공간

- **K_rot 하한:** 무게 피드포워드는 손끝 기준점의 힘입니다. 손잡이 중심까지 r = 20.5 mm(tool offset) 떨어진 하중은 모멘트 M = F·r = 0.101 N·m를 남깁니다.
  - K_rot ≥ M/θ_max = 2.88 N·m/rad → **K_rot = 5 N·m/rad** (1.5배)
  - 상한은 ⑦의 ρ 판정에 함께 들어 있습니다.
- **영공간 τ0:** K_i = M_ii ω², D_i = 2ζ M_ii ω (문서 2쪽 식을 관절 공간에 적용)
  - ω = 작업공간에서 가장 느린 축(z)의 ωn = **8.1 rad/s** (자세 유지가 작업보다 빠르지 않게)

## ⑨ 그리퍼 쥐는 힘 (⑥의 F_int,max와 같은 숫자에서)

- **필요 힘:** 손잡이 양면 마찰 2μN ≥ SF·√((m g/4)² + F_int,max²) → **N ≥ 15.8 N**
- **가상일:** 손끝 간격 기울기 dgap/dq = −111.9 mm/rad (손잡이 30 mm에 닿는 q = 0.855).
  - 구동 관절은 한쪽 손가락, 즉 간격의 절반을 움직입니다.
  - τ_grip = N·|dgap/dq|/2 = **0.88 N·m**
- **시뮬:** 그리퍼 구동 관절의 effort 한계 = τ_grip
  - mimic 관절은 실물에선 강체 링크라 한계를 낮추지 않습니다. 낮췄더니 손잡이에 밀려 접혀 파지에 실패했습니다(11/5 확인).
- **실물:** RH-P12-RN 전류 한계로 같은 τ를 설정합니다.
- 고정 구속 없이 접촉 마찰로 들고 있으므로 미끄러짐도 시뮬에 반영됩니다.

**남은 확인**
- **잔떨림:** 계단 응답 뒤 ±1 ~ 2 mm 잔떨림이 있고, F_cmd가 ±40 N으로 요동합니다. 문서 5쪽 실수 2(D가 속도 잡음을 증폭)와 같은 현상인지 확인해야 합니다. 대응 후보는 1차 LPF이며, 차단주파수를 ωn보다 충분히 높게 둡니다.
- **실물 τ_s 측정 → ④ → K_F 재확인:** 측정한 τ_s로 계산한 마찰 하한이 K_F = 40보다 크면 사양을 다시 정해야 합니다(Δ를 줄이는 쪽).
